# Supplementary course notebook

`OptiEnergy_University_Project.ipynb` is the comprehensive original course edition, including mathematical notes, viva preparation, academic report generation, and optional app export. It contains an observed hourly cache for offline use after dependency installation.

Use the refined [`../OptiEnergy_AI.ipynb`](../OptiEnergy_AI.ipynb) as the main portfolio notebook. Its separate later-period forecasting benchmark includes three outer temporal folds, naive/boosted-tree references, ablations, and paired uncertainty analysis. The original course notebook's early-window results concern a different experiment; they must not be compared as if they used the same holdout.
