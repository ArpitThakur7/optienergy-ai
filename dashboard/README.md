# OptiEnergy AI: original optimization dashboard

This is the complete seven-page Streamlit implementation for the original optimizer study. The repository's primary [portfolio notebook](../OptiEnergy_AI.ipynb) contains the stronger, separate later-period forecasting benchmark.

## Run

From the repository root:

```bash
python -m pip install -r dashboard/requirements.txt
cd dashboard
python -m streamlit run app.py
```

The included processed hourly UCI cache, measured optimizer-demo CSVs, and trusted champion checkpoint make the overview and historical prediction pages usable immediately. The model was generated by this project; do not replace it with an untrusted pickle/joblib file.

## Reproduce

Run from this directory:

```bash
python -m pytest -q
python -m src.experiments --mode demo
python -m src.build_report --mode demo
```

The demo uses 2,400 early clock hours, three seeds, and a 10-epoch baseline. Its scores and linear/Momentum selection concern that early-window study, not the top-level temporal benchmark. The complete optimizer grid is implemented under `--mode full` but was not pre-executed.

The reports directory includes the academic PDF, mathematical derivations, experimental analysis, presentation content, architecture, and viva notes. The complete course notebook is `../notebooks/OptiEnergy_University_Project.ipynb`.

For a fresh official UCI download use `python -m src.data_loader --force`. Dataset: Hebrail & Berard (2006), UCI Individual Household Electric Power Consumption, https://doi.org/10.24432/C58K54, CC BY 4.0. Complete hourly kWh is sum(minute kW)/60; index t labels [t-1h,t). Targets are never imputed. Scalers fit on chronological training data only.
